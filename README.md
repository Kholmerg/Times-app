# Табель — учёт рабочего времени

Сайт для отметки смен: вход/выход, несколько компаний, старшие по компаниям, расчёт зарплаты с переработками, выгрузка в Excel.

- `index.html` — весь сайт (Firebase Auth + Firestore).
- `firestore.rules` — правила защиты базы. Вставляются в Firebase → Firestore Database → Rules → Publish.
